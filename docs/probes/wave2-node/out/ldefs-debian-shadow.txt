# Post-pass probe (2026-10-16, stunt node anas-pve, PVE 9 / Debian 13): how Debian's shadow parses
# login.defs USERGROUPS_ENAB — real `userdel -P <prefix> carol` over a prefix tree (passwd carol:1004:1005,
# group carol:x:1005: empty, no other members or primaries), one tree per login.defs body. The earlier
# proofs (cross-model reviews of cr.29d/cr.29e) ran on Fedora's shadow 4.19.0, which parses login.defs
# through libeconf; Debian's `passwd` package links no libeconf and uses shadow's own getdef parser.
# Script: docs/probes/wave2-node/ldefs-probe.sh (run as root over ssh; the tree is removed after).
$ dpkg-query -W passwd login; ldd /usr/sbin/userdel | grep -i econf

passwd 1:4.17.4-2

scenario          login.defs body                      result (carol group)

yes_note          USERGROUPS_ENAB yes # note           rc=0 group-KEPT      <- inline comment NOT stripped
yes_tab_note      USERGROUPS_ENAB yes<TAB># note       rc=0 group-KEPT

yes_hashx         USERGROUPS_ENAB yes#x                rc=0 group-KEPT
